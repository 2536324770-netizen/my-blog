方案 A // 最推荐新手 耗时 ~30 秒

文章列表

无需配置 Git 或命令行。每次你在网页里写完新文章或导入 .md 后，直接导出烘焙好的 index.html 上传即可：

  1. 在本页点击上方 「📦 一键烘焙并下载 index.html」，将下载的 index.html 放入一个新建文件夹（如 my-blog/index.html）。
  2. 登录 Cloudflare 控制台 → 左侧点击 Compute (Workers & Pages) → Create → 切换到 Pages 标签页。
  3. 选择 Use direct upload (直接上传)，输入项目名（如 laterano-blog），将刚才的文件夹拖入页面并点击 Deploy site！
  4. 部署完成后即可获得免费的 *.pages.dev 全球加速域名，也可在 Custom domains 绑定你自己的域名。
↗ 查看官方 Direct Upload 文档
方案 B // Git 自动构建 GitHub 持续集成

2. GitHub 仓库联动自动部署

如果你习惯用 Git 管理博客版本，只需将导出的 index.html 与 posts.json 推送至 GitHub 仓库：

  1. 创建一个 GitHub 仓库，把导出的 index.html 放在仓库根目录。
  2. 在 Cloudflare Pages 创建页面选择 Import an existing Git repository，授权并选择你的仓库。
  3. Build settings (构建设置) 保持全空即可：Framework preset 选 None，Build command 留空，Build output directory 填 /。
  4. 以后每次 git push 更新 index.html，Cloudflare Pages 会在 15 秒内自动同步上线！
↗ 查看 Cloudflare Pages 官方指南
